I build AI/ML systems that ship to production: LLM infrastructure, coding agents and the harnesses around them, RAG and fine-tuning, and computer vision.

🚀 **Currently:** I'm at Anthropic.

🎓 **Previously:**
- **Secludy AI**, Founding Forward Deployed Engineer. Scaled production LLM traffic to 100M tokens and 100K requests per minute with a Kubernetes-autoscaled load balancer. Built an automated software factory (CI/CD, tests, linters) that took feature delivery from weeks to days. Hit 0.998 F1 across 56 PII types on leak-free held-out data.
- **GEICO**, AI/ML Software Engineer II. Shipped 5+ AI/ML developer tools used by 1,000+ engineers, including a coding assistant on open-source LLMs and a RAG pipeline that cut debug time 90%. Fine-tuned LLMs on synthetic data, and got promoted to Engineer II in under a year.
- **Omni Sciences**, Software Engineer - ML. Led a 4-engineer team that took a contactless heart rate sensor from 0→1 (I reverse-engineered the camera hardware, taught myself Fourier transforms, and got it running faster than real time).

🛠️ **Recent projects:**
- **AI-driven CAD for an assistive bionic glove:** MCP servers that let AI agents drive Onshape and CadQuery, plus FEA stress runs and 492K exact-geometry collision checks across 108 poses.
- **Automated LLM red-teaming with evolutionary search:** got [ShinkaEvolve](https://github.com/MuhsinunC/ShinkaEvolve) to 400 generations an hour with 300+ parallel evals and adaptive rate limiting, and made its crash recovery about 1000x faster.
- Older ones: [dog breed classification with deep CNNs](https://github.com/MuhsinunC/Dog-Image-Classification-Deep-CNN) and a [sentiment classifier](https://github.com/MuhsinunC/Sentiment-Classifier).

🔬 **Research & writing:** Published work on contactless vitals monitoring with near-infrared Time-of-Flight cameras, computer vision, and ML. I'm on the cover of a linear algebra textbook for revising its core sections. On Medium I've written about [RAG vs. fine-tuning](https://medium.com/@muhsinunc/rag-vs-fine-tuning-when-to-retrieve-and-when-to-train-65e2a08da6b4), [DeepSeek Coder vs. CodeLlama](https://medium.com/@muhsinunc/deepseek-coder-vs-codellama-which-open-source-model-actually-helps-you-ship-e0ec5bd89a78), and [a deep learning pipeline for dog breeds](https://medium.com/@muhsinunc/building-a-deep-learning-pipeline-to-identify-dog-breeds-8bd0461de4d7).

📚 **Education:** B.S. Computer Science, University of Michigan, 2023.
